# Agent Documentation Hub

Welcome, agent. This folder contains specialized documentation to help you understand the Tilper AI codebase and how to interact with it effectively.

## Documentation Index

1.  **[STEERING.md](./STEERING.md)**: **Read this first.** Contains behavioral guidelines, project vision, and core principles for AI agents.
2.  **[ARCHITECTURE.md](./ARCHITECTURE.md)**: Deep dive into the system components, data flow, and key file locations.
3.  **[TECH_STACK.md](./TECH_STACK.md)**: Comprehensive list of technologies and libraries used in the project.

## How to use this documentation

- Use **STEERING.md** to understand the "soul" of the project and how you should communicate/act.
- Use **ARCHITECTURE.md** when you need to know where to implement a feature or how different parts of the system interact.
- Use **TECH_STACK.md** to ensure you are using the correct libraries and following the established technical patterns.

*Note: For a high-level overview of the project features and recent changes, you can also refer to `agents.md` in the root directory.*
